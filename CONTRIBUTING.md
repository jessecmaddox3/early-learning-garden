# Contributing

Useful improvements include better clues and accessibility, tested browser fixes, improved local recording tools and clearly sourced teaching corrections. Keep all four games usable and preserve synthetic examples.

Open an issue with a made-up example and reproduction steps. Leave out real learner names, recordings, backups and backend configuration. Voice assets need their own documented rights and listening review. Do not treat ordinary TTS as validated phoneme pronunciation.

Use Node22 or later, npm ci --ignore-scripts, npm test and npm run build. Run the relevant browser/Python checks listed in README. A local/cloud change also needs ownership and actual disposable provider coverage. Update beginner instructions when behavior changes; keep the MIT and dependency notices.
