# Source and asset provenance

> **TL;DR:** Four original personal games, complete teaching banks and recording workflow, extracted into fresh public history. No household records, backend configuration or voice recordings are included.

Sixteen owned inputs form the original extraction: the picture menu, its styles/manifest, four game pages/controllers, the shared visual/audio shell, empty recording manifest, recording notes and script. The original personal progress module was excluded completely. Private profile/research notes, analytics, surrounding pages and Git history were excluded. Public instructions restate the useful design without personal circumstances.

All 12 original words and 18 letters remain. The public implementation fixes scoring and persistence, adds reachable controls and uses a correct short-i insect anchor. The extra x sound is for the original word fox. Teaching facts and limitations are explained in [design notes](design.md).

Local/cloud storage, owner-isolated database schema and integration tooling derive from [Morphology Forge 1.0.0](https://github.com/jessecmaddox3/morphology-forge/tree/863567445a7544522f57b7bad247aba834536cd9), also MIT licensed. Each game uses a separate identifier/database and curriculum shape. No included account or shared backend exists.

Gameplay uses original CSS, system fonts, native emoji and generated oscillator chimes. No copied audio pack or illustration library is included. The banner was generated with ChatGPT from the [saved brief](hero-prompt.txt), with no personal photographs, likenesses or brands. Generation metadata is retained. It is promotional illustration, not a screenshot.

The original AI-assisted code and teaching bank use the [MIT license](../LICENSE). The optional cloud SDK uses exact locked dependencies with their original notices, recorded in [the manifest](../licenses/npm/SOURCES.json) and [combined notices](../public/THIRD_PARTY_NOTICES.txt). User-added recordings have separate rights; the app's license grants no permission to redistribute another person's voice or source audio.
